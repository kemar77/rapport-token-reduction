1 · The meter

What is a token?

An AI model doesn't read words — it reads tokens: small chunks of text worth roughly 3.5 English characters each on most Claude models (the newest 4.7+ models spread the same text across ~30% more tokens — source). Everything your agent touches becomes tokens: your prompts, whole files it opens, and every command output it reads.

And you pay both directions, like a toll booth charging every car twice: input tokens (what goes in) and output tokens (what comes out). Output is the expensive direction — on today's Claude models it costs exactly 5× the input price.

2 · The invisible lever

The cache: your agent's biggest discount

Here's the part nobody tells beginners: every time you send a message, the entire conversation — all previous turns, files, and outputs — is re-sent to the model as input. Without a cache, turn 40 pays full price for turns 1 through 39, all over again, every single time.

Prompt caching fixes this. The provider remembers the unchanged beginning of the conversation (the "prefix") and re-reads it at a fraction of the price:

  • ●Cache read = 0.1× the input price — a 90% discount (0.05× on Sonnet 5.5 and Opus 5.5, and as low as 0.025× — 97.5% off — on the very newest).
  • ●Cache write costs +25% once, when a new prefix is stored (a TTL — time-to-live — of 5 minutes on API keys; the stored copy is refreshed for free every time you use it, a "cache hit").

When does the discount disappear? On a cache miss — and that's the one thing to protect. The cache only survives if the beginning of the conversation stays byte-for-byte identical:

"Cache hits require 100% identical prompt segments." Changing the system prompt (the standing instructions the agent starts every conversation with), the tools list (the set of functions the agent may call), or anything before your latest message invalidates everything after it — and the whole conversation is re-billed at full price. — Anthropic, Prompt caching docs

Think of a highway toll pass: as long as the windshield tag stays visible and untouched, the barrier opens at the discount rate. Swap the windshield sticker mid-trip — new system prompt, swapped model, edited first message — and you pay the full toll on the whole road again. One practical detail: on API keys the cache lives 5 minutes; on Claude subscriptions it lives 1 hour. Either way it refreshes free each time you hit it — work in bursts, and it stays warm. (Everything the model can "see" at once — its working memory — is called its context window — the cache keeps most of that context at the discount rate.)

3 · Zero-cost habits

The free wins (no tool required)

Before installing anything, four habits cut the bill today — each one is the official recommendation, not folk wisdom:

  • Keep your context file lean. CLAUDE.md (Claude Code) and AGENTS.md (Codex) are loaded at the start of every session and re-sent on every request. The official advice: "aim to keep CLAUDE.md under 200 lines." Codex caps the combined instruction files at 32 KiB but still injects them everywhere. (costs · memory · AGENTS.md)
  • Compact instead of clearing. When the context window fills, /compact summarizes the conversation mid-task (Claude Code also auto-compacts when you approach the limit); /context shows a colored grid of what's eating it. Switching tasks? /clear — stale context is billed on every later message. (commands)
  • Delegate heavy reading to subagents. A subagent is a helper instance the main agent spawns; it runs in its own isolated context window — it wades through logs and files, and only the short summary returns to your main thread. Fair warning from the docs: each subagent spends tokens of its own. (sub-agents)
  • Read with a scalpel, not a bulldozer. Never dump a whole file or a raw command. Claude Code's hooks (small scripts the tool runs before/after each command) can enforce this for you: the docs show a test-run hook that greps errors and keeps only the first 100 lines — turning "tens of thousands of tokens" into "hundreds." (costs)

Just switching to Codex? OpenAI's caching is automatic (up to 95% off reused tokens, 30-minute TTL) — same prefix rule applies (docs). The habits above are identical.

4 · Automate it

RTK: the filter we measured

Everything in section 3 asks the agent to be disciplined. RTK doesn't ask — it enforces. It's a small Rust program (github.com/rtk-ai/rtk, Apache-2.0, single binary) that sits between your agent and the terminal: every command the agent runs goes through it, and only a compact, filtered summary reaches the model. Its README claims 60–90% reduction on common dev commands.

This isn't marketing — it's what we measured on our own machine, on real work:

Install RTK
winget install rtk-ai.rtk   # Windows
# macOS / Linux: brew install rtk
rtk init --global              # wires the hook into Claude Code

Windows users: just two commands — winget install rtk-ai.rtk then rtk init --global. The brew line is for macOS/Linux only.

🚫 Don't run cargo install rtk — that installs a different project called "Rust Type Kit" (a real name collision, documented in RTK's own README). Verify with rtk --version.

5 · Steal these

The copy-paste kit

Paste block A (or B) once, and your agent follows the discipline from section 3 on every task. Block C finds your personal waste.

A · paste into CLAUDE.md (Claude Code)
# Token discipline
- Before reading a whole file, grep the relevant section and read only that.
- Never dump full command output; pipe through head -100 or filter with grep.
- When a command is verbose, report a one-sentence summary, not the raw text.
- If the context window fills mid-task, run /compact instead of /clear.
- Keep my instructions files short: this file must stay under 200 lines.
B · paste into AGENTS.md (Codex CLI)
# Token discipline
- Read files surgically: locate with grep first, read the matching range only.
- Truncate terminal output: `<command> 2>&1 | head -100` unless full output is needed.
- Summarize verbose results in one sentence instead of echoing them.
- Keep AGENTS.md minimal — it is injected into every request (32 KiB cap).
C · one-shot waste audit (any agent)
Audit my last session's token usage: list the 5 heaviest
sources of waste (files read whole, raw command dumps,
repeated context), and tell me the single command I
should stop running raw.
