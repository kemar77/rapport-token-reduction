1 · Qui est ce client

Dix choses que vos propres mots nous ont apprises

1. « Consulting » est un sous-comptage — vous dirigez quatre entreprises en une

Votre spéc dit que le système « soutient l'administration personnelle, le conseil H&S, les services de drones, l'œuvre caritative football sud-africaine, la surveillance de sécurité et la production documentaire professionnelle », et demande des « profils de connaissances séparés et autorisés » par contexte. Nous le prenons au sérieux : ce sont quatre mémoires, et la séparation est votre design — nous la construisons comme spécifiée.

2. Le garde-fou humain est votre idée, par écrit

« Always have a human in loop to ensure agents don't make decisions without human consent » — votre formulaire, multi-agents

Votre spéc l'opérationnalise (« Send emails / contact leads — Approval », « Book travel / spend money — Approval », « Never automatically install software, rotate credentials, disable accounts or delete data without an authorised policy or approval »). Nous sommes alignés avant le premier appel — c'est du design de confiance, pas un argument de vente.

3. Vous voulez trois choses à la fois — et c'est soluble

« Set it up for me » sur 8 solutions sur 12, apprendre « done with me », confier l'inverse « teach me », outils à « $0 free only ». Prises de front, quelqu'un perd. La résolution est dans le séquençage, pas dans une remise : chaque module est un produit unique qui livre les deux — nous pilotons l'installation, vous gardez le tutoriel pas à pas à vie. Résultat DFY, compétence DWY.

4. Vous avez nommé le produit vous-même : « Not enough skills »

Votre goulot n°1, déclaré alors que vous utilisez Claude Code tous les jours. Un utilisateur quotidien qui se sent encore sous-formé est exactement la cible des tutoriels de transfert de compétence — pas d'un logiciel boîte noire. Et comme votre budget formation est en sessions live, chaque module se rentabilise plus vite.

5. Votre définition du succès est la réparabilité, pas la magie

« A workable AI system that is easy to manage and knowledge to fix when it does wrong » — votre objectif 90 jours, verbatim

« Knowledge to fix when it does wrong » est le meilleur allié possible du modèle tutoriel. Chaque module se termine par le système qui tourne et une section « quand ça casse ». Vous refusez explicitement la dépendance envers nous — le design le respecte.

6. Le cycle des subventions caritatives est votre première victoire mesurable

Votre demande verbatim : « Research for funding proposals for charity in South Africa and share in pdf ». Votre spéc précise : « identifier les subventions football sud-africain, sponsors, deadlines, éligibilité, documents requis ». Les subventions ont des échéances — un tableau de score intégré. Et le flux chaîne deux de vos agents : recherche (A2) vers document (A4).

7. Une horloge 60 jours tourne déjà

« First revenue: Within 60 days. » L'ordre des modules est construit pour ça : premier digest semaine 3, premier registre semaine 4, pipeline subventions semaine 6. Ce qui disqualifie volontairement les starts à rentabilité lente — SEO et vidéo arrivent après J+60, exprès.

8. La sensibilité au prix porte sur les outils, pas sur l'expertise

« $0 free only » par mois, mais aucun plafond déclaré sur les achats ponctuels. Aujourd'hui vous payez « Up to $50/month ». Le levier est arithmétique : le premier module route cette dépense vers les modèles gratuits — un module à 150 $ qui annule une facture de 50 $/mois se rembourse en environ trois mois.

9. Votre spéc est exceptionnellement mûre — c'est une livraison, pas une découverte

Vous avez déjà écrit les tests d'acceptation (« Every task has an ID, owner, status… »), un plan de livraison en 5 phases, une matrice d'approbation, et 5 décisions ouvertes. Notre devis répond à vos phases — il ne les réinvente pas.

10. « Not sure / several » machines — le local d'abord, un serveur ensuite

Plusieurs machines conviennent à la pile locale gratuite. L'agent de nuit permanent est ce qui justifiera éventuellement un seul petit serveur — et seulement quand la Phase 1 tourne démontrablement.

3 · La tension budgétaire, résolue

DFY × apprendre avec moi × 0 $ — la pyramide

Chaque étage finance le suivant :

Phase 1 — semaines 1-4 : apprendre sur votre machine, 0 $ d'outils

Nous installons ensemble : le routage d'abord (M1) — vos « Up to $50/month » tombent vers 0 $, ce qui rend votre budget « $0 free only » vrai au lieu d'aspirationnel — puis Claude Code pro (M2) et le brief du matin (M3), gratuit et local. Votre objectif 90 jours (« knowledge to fix when it does wrong ») est un livrable de Phase 1, pas une promesse.

Phase 2 — semaines 3-6 : les registres

Moteur de recherche + registre d'opportunités (M4), la mémoire à quatre contextes autorisés (M5), et le pipeline de subventions caritatives (M6) — le cas d'usage que vous avez proposé verbatim. C'est exactement la Phase 2 de votre spéc.

Phase 3+ — semaines 5-8 : documents et vigies

Documents brandés (M7), votre matrice d'approbation forcée dans le code (M8), puis — seulement quand la Phase 1 tourne démontrablement — le serveur permanent (M9) : ~6-12 $/mois, le seul vrai coût mensuel. Aucun autre frais récurrent n'existe. La GPU louée reste une décision optionnelle dans M10 ; par défaut : pas nécessaire.

Le build OpenClaw complet — votre spéc §7 phases 1-5, les quatre agents, une porte d'instruction unique, les scopes OAuth, la télémétrie, les tests d'acceptation signés — est l'offre custom. Chiffrée après livraison de M1 + M3 : nous chiffrons contre votre vraie machine, votre vraie boîte mail, votre vrai Drive (vos §8 listent les inconnues). Règle annoncée d'avance : nous chiffrons quand nous pouvons mesurer.

5 · Les risques

Nommés avant que vous les trouviez

R1 — Le OAuth est la vraie montagne

L'accès scopé Gmail/Drive/Calendar est le chantier le plus délicat. Parade : lecture seule d'abord, brouillons étiquetés, envoi sur approbation, tokens révocables — votre §6 le demande exactement. Du mou est prévu en M3/M8 plutôt qu'une date promise.

R2 — Quatre entreprises, quatre mémoires, un seul cerveau

La contamination croisée — un prix de drone dans une lettre de subvention, des données caritatives dans un dossier de conseil — est la panne silencieuse la plus probable. M5 construit les quatre profils autorisés avant que la recherche intensive démarre, sur votre propre taxonomie.

R3 — Le piège du 0 $

« $0 free only » tient jusqu'à la semaine 6. Le serveur est le seul coût mensuel réel (~6-12 $/mois) ; une facture surprise plus tard coûte plus de confiance que la vérité n'en coûte aujourd'hui — alors la voilà.

R4 — Nous planifions contre des inconnues

Volume « pas encore sûr », client idéal non défini, matériel incertain. Le plan optimise votre usage principal déclaré (« Save me time ») et se re-contrôle au checkpoint de la semaine 4 avant d'engager M6-M10.

R5 — La friction d'approbation peut manger le temps gagné

Votre politique est riche en approbations et votre but est le temps. Si chaque action vous dérange dans la journée, le garde-fou devient le fardeau. Remède par votre propre design : les approbations groupées dans le brief du matin, oui/non en un tap — le human-in-loop coûte des minutes, pas des interruptions.
